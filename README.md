# DOM-gissningen

En övning i DOM-manipulation med JavaScript. Sidan har 10 knappar och 10 funktioner (A–J). Din uppgift är att lista ut vilken funktion varje knapp kör.

## Så gör du

1. Klicka på knapparna och titta noga på vad som händer på sidan.
2. Läs funktionerna A–J till höger.
3. Välj din gissning i rullgardinsmenyn under varje knapp.
4. Klicka på **Rätta** för att se hur många du fick rätt.
5. Klicka på **Återställ sidan** om du vill börja om från början.

## Tips

- Flera funktioner ändrar samma element. Läs koden noga och se vad som skiljer dem åt.
- Ordningen du klickar i spelar roll. En knapp kan ge olika resultat beroende på vad du har klickat på innan.
- Öppna konsolen (F12) om en knapp inte verkar göra något. Där kan det stå ett felmeddelande.
- Fusk är inte tillåtet: titta inte i källkoden efter facit!

## Det här övar du på

- `querySelector`, `querySelectorAll` och `getElementById`
- `createElement` och `appendChild`
- `textContent`, `style` och `classList`
- `forEach` med `index`
- `if/else` och `%` (modulo)
- CSS-selektorn `:nth-child()`

## Kör lokalt

Ladda ner eller klona repot och öppna `index.html` i webbläsaren. Inga beroenden behövs.
